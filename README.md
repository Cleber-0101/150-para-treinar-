# Treino de Fundamentos — 150 exercícios de lógica em JavaScript

Exercícios do básico ao avançado: lógica, algoritmos, estruturas de dados e objetos.
**Nenhum exercício tem resposta.** Cada arquivo traz apenas o enunciado e a saída
que o seu código deve produzir no console. A lógica é com você.

## Como usar

1. Abra o arquivo do exercício.
2. Leia o **ENUNCIADO** e a **SAÍDA ESPERADA NO CONSOLE**.
3. Escreva sua solução abaixo da linha `// ===== Escreva sua solução abaixo =====`.
4. Execute no terminal, a partir desta pasta:

   ```
   node 01-variaveis-tipos-e-operadores/ex001-apresentacao.js
   ```

5. Compare o que apareceu no console com a saída esperada. Precisa ser **idêntico**.
6. Marque o exercício como feito neste README trocando `[ ]` por `[x]`.

## Regras do treino

- Quando o enunciado proibir um recurso (ex.: "sem usar sort", "sem Math.max"), respeite.
  O objetivo é construir a lógica, não decorar métodos prontos.
- Não altere os dados fornecidos no exercício. Depois de acertar, teste com outros
  valores para garantir que sua lógica funciona em qualquer caso.
- Quando a saída mostra um array ou objeto (ex.: `[ 1, 2, 3 ]`), ela é o resultado de
  `console.log(valor)` direto, no formato que o Node.js usa para exibir.
- Travou? Releia o enunciado, escreva a lógica em português (pseudocódigo) e só depois
  traduza para JavaScript.
